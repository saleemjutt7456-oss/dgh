# dgh

A demo repository used to test pushing changes to GitHub.

## About

This repo is a simple sandbox. It exists to confirm that creating, committing
and pushing files works end to end.

## Getting started

```bash
git clone https://github.com/saleemjutt7456-oss/dgh.git
cd dgh
```

## Demo test

To check that the setup works:

1. Edit this file or add a new one.
2. Commit the change: `git commit -am "Demo test"`
3. Push it: `git push origin main`
4. Open the repository page on GitHub and confirm the change appears.
